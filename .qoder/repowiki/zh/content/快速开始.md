## 简介
WireGuard-Go 是 WireGuard 的 Go 语言实现，提供跨平台的 VPN 解决方案。本指南将帮助您快速安装、配置和使用 WireGuard-Go，涵盖从基础设置到高级配置的完整流程。

WireGuard-Go 的主要特点：
- **高性能**：基于现代加密算法，提供出色的网络性能
- **简单易用**：简洁的配置语法和直观的管理接口
- **跨平台**：支持 Linux、macOS、Windows、FreeBSD、OpenBSD 等主流操作系统
- **安全加密**：使用 Noise 协议进行端到端加密通信

## 安装与运行

### 从源码编译

#### 环境要求
- Go 1.23.1 或更高版本
- Git 版本控制系统
- 适当的系统权限（创建 TUN 设备需要管理员/root 权限）

#### 编译步骤
```bash
# 克隆仓库
git clone https://git.zx2c4.com/wireguard-go
cd wireguard-go

# 使用 Makefile 构建
make

# 或者直接使用 Go 工具链
go build -o wireguard-go
```

#### 安装二进制文件
```bash
# 安装到系统路径
sudo make install

# 或者手动复制到目标目录
sudo cp wireguard-go /usr/local/bin/
```

### 预编译二进制文件
对于大多数用户，建议直接使用预编译的二进制文件：

1. 访问 [WireGuard 官方下载页面](https://www.wireguard.com/install/)
2. 选择对应平台的预编译版本
3. 验证文件完整性（如提供签名）
4. 赋予执行权限并运行

## 平台支持

### Linux
- **推荐方式**：优先使用内核模块，性能更好且与系统集成更紧密
- **wireguard-go 适用场景**：当无法安装内核模块时的替代方案
- **TUN 设备**：通过 `/dev/net/tun` 创建虚拟网卡
- **特性支持**：完整的 GSO、标记等功能支持

### macOS
- **驱动支持**：使用 utun 驱动
- **限制说明**：不支持 sticky socket，由于 Darwin 限制不支持 fwmark
- **接口命名**：必须使用 `utun[0-9]+` 格式或让内核自动选择
- **环境变量**：可通过 `WG_TUN_NAME_FILE` 获取实际接口名称

### Windows
- **推荐方式**：使用功能更完善的 Windows 应用
- **当前状态**：作为测试程序存在，主要用于调试 Go 包
- **生产环境**：建议使用 [WireGuard for Windows](https://git.zx2c4.com/wireguard-windows/about/)

### FreeBSD/OpenBSD
- **特性支持**：不支持 sticky socket
- **标记映射**：FreeBSD 映射到 `SO_USER_COOKIE`，OpenBSD 映射到 `SO_RTABLE`
- **接口命名**：OpenBSD 必须使用 `tun[0-9]+` 格式

## 基本用法

### 启动服务
```bash
# 后台模式运行（默认）
wireguard-go wg0

# 前台模式运行（便于调试）
wireguard-go -f wg0

# 指定日志级别
LOG_LEVEL=debug wireguard-go wg0
```

### 配置接口
使用 `wg` 命令配置 WireGuard 接口：

```bash
# 查看接口状态
wg show wg0

# 设置私钥
wg set wg0 private-key <私钥文件路径>

# 添加对等体
wg set wg0 peer <公钥> allowed-ips <IP范围> endpoint <对端地址:端口>

# 保存配置
wg-quick save wg0
```

### 管理接口
```bash
# 启动接口
ip link add wg0 type wireguard
ip addr add <IP地址>/<掩码> dev wg0
ip link set wg0 up

# 停止接口
ip link del wg0
```

## 配置文件示例

### 服务端配置示例
```ini
[Interface]
PrivateKey = server_private_key
Address = 10.0.0.1/24
ListenPort = 51820

[Peer]
PublicKey = client_public_key
AllowedIPs = 10.0.0.2/32
PersistentKeepalive = 25
```

### 客户端配置示例
```ini
[Interface]
PrivateKey = client_private_key
Address = 10.0.0.2/24

[Peer]
PublicKey = server_public_key
Endpoint = server_public_ip:51820
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25
```

### 关键参数说明
- **PrivateKey/PublicKey**：用于密钥协商的本地和对端密钥
- **Address**：接口的 IP 地址和子网掩码
- **ListenPort**：服务端监听的 UDP 端口
- **Endpoint**：对端的公网地址和端口
- **AllowedIPs**：允许通过隧道传输的 IP 地址范围
- **PersistentKeepalive**：保活间隔（秒），用于 NAT 穿透

## 常见使用场景

### 点对点连接
最简单的 VPN 连接场景，两台主机直接建立加密隧道：

1. **生成密钥对**
   ```bash
   # 服务器端
   wg genkey | tee server_private_key | wg pubkey > server_public_key
   
   # 客户端
   wg genkey | tee client_private_key | wg pubkey > client_public_key
   ```

2. **配置服务器**
   ```ini
   [Interface]
   PrivateKey = server_private_key
   Address = 10.0.0.1/24
   ListenPort = 51820
   
   [Peer]
   PublicKey = client_public_key
   AllowedIPs = 10.0.0.2/32
   ```

3. **配置客户端**
   ```ini
   [Interface]
   PrivateKey = client_private_key
   Address = 10.0.0.2/24
   
   [Peer]
   PublicKey = server_public_key
   Endpoint = server_public_ip:51820
   AllowedIPs = 0.0.0.0/0
   ```

### 多节点网络
中心节点作为路由节点，多个客户端连接到中心：

```ini
# 中心节点配置
[Interface]
PrivateKey = center_private_key
Address = 10.0.0.1/24
PostUp = iptables -A FORWARD -i %i -j ACCEPT; iptables -A FORWARD -o %i -j ACCEPT

[Peer]
PublicKey = node1_public_key
AllowedIPs = 10.0.0.2/32

[Peer]
PublicKey = node2_public_key
AllowedIPs = 10.0.0.3/32
```

### NAT/防火墙穿透
针对处于 NAT 后的客户端：

```ini
[Peer]
PublicKey = server_public_key
Endpoint = server_public_ip:51820
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25
```

## 故障排除

### 常见问题及解决方案

#### 无法创建 TUN 设备
**问题现象**：启动时报错 "Failed to create TUN device"

**解决方案**：
1. 确认以管理员/root 权限运行
2. 检查系统是否加载了必要的内核模块
3. Linux 系统：`modprobe tun`
4. 检查 `/dev/net/tun` 是否存在

#### 端口绑定失败
**问题现象**：报错 "bind error" 或 "address already in use"

**解决方案**：
1. 检查端口是否被占用：`netstat -tlnp | grep 51820`
2. 修改监听端口或停止占用进程
3. 确认防火墙规则允许该端口

#### 无法建立连接
**问题现象**：客户端能启动但无法建立隧道

**排查步骤**：
1. 检查双方公钥是否正确
2. 确认对端地址和端口可达
3. 检查防火墙/NAT 规则
4. 验证时间同步（NTP）

#### 频繁断连
**问题现象**：连接不稳定，频繁断开重连

**解决方案**：
1. 调整 Keepalive 间隔
2. 检查中间网络设备是否丢弃空闲连接
3. 优化网络质量
4. 调整 MTU 避免分片

#### 速度慢或丢包
**问题现象**：VPN 连接速度缓慢或数据包丢失

**优化措施**：
1. 调整 MTU 到合适值
2. 关闭不必要的日志输出
3. 评估链路质量和拥塞情况
4. 考虑使用 UDP 而非 TCP

## 构建与部署

### 开发环境搭建
```bash
# 安装依赖
go mod download

# 运行测试
go test ./...

# 构建可执行文件
go build -v -o wireguard-go
```

### 交叉编译
```bash
# 为不同平台编译
GOOS=linux GOARCH=amd64 go build -o wireguard-go-linux-amd64
GOOS=darwin GOARCH=arm64 go build -o wireguard-go-darwin-arm64
GOOS=windows GOARCH=amd64 go build -o wireguard-go-windows.exe
```

### 容器化部署
```dockerfile
FROM golang:1.23-alpine AS builder
WORKDIR /app
COPY . .
RUN go build -o wireguard-go

FROM alpine:latest
RUN apk add --no-cache iproute2
COPY --from=builder /app/wireguard-go /usr/local/bin/
ENTRYPOINT ["wireguard-go"]
```

### 生产环境部署建议
1. **权限最小化**：使用专用用户运行服务
2. **日志轮转**：配置 logrotate 管理日志文件
3. **健康检查**：实现服务健康检查机制
4. **监控告警**：监控连接数和性能指标
5. **备份策略**：定期备份配置文件和密钥
