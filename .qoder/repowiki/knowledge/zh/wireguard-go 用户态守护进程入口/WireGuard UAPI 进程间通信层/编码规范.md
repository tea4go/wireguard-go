- 每个平台通过独立的 `uapi_<os>.go` 文件配合 Go build tag 提供同名的 `UAPIListener` 类型与 `UAPIListen`/`UAPIOpen` 函数，对外暴露一致的方法集 `Accept`/`Close`/`Addr`。
- 错误码统一以负数形式导出（如 `IpcErrorIO`、`IpcErrorProtocol`），Unix 端直接映射 `golang.org/x/sys/unix` 的 errno，Windows 端使用硬编码的 Win32 错误码。
- 监听器内部使用带缓冲的 `connNew`/`connErr` channel 将底层 `Accept` 循环与错误传播解耦，`Accept()` 通过 `select` 在这两个 channel 之间选择返回。
- Unix 监听器在关闭 socket 后通过系统事件机制（Linux 的 inotify、BSD 的 kqueue+EVFILT_VNODE）检测 socket 文件被删除，并将结果通过 `connErr` 通道上报以优雅退出。
- Windows named pipe 实现将配置封装为 `DialConfig`/`ListenConfig` 结构体，并提供带默认值的便捷函数（如 `DialTimeout`、`Listen`）供上层直接调用。
