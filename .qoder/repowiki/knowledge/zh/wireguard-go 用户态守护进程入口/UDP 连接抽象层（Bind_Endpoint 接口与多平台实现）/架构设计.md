模块以 conn.go 中定义的 Bind、Endpoint、ReceiveFunc 三个核心接口为边界，向上层 wireguard-go 提供统一的 UDP 收发抽象；具体实现通过 Go build tag 文件拆分：
- bind_std.go：跨平台 StdNetBind，基于 net.UDPConn + golang.org/x/net/ipv4/ipv6.PacketConn 实现，使用 sync.Pool 复用 ipv6.Message 与 net.UDPAddr，在 Linux/Android 上启用 ReadBatch/WriteBatch 进行批量收发，并通过 coalesceMessages/splitCoalescedMessages 实现 UDP GSO/GRO。
- bind_windows.go：WinRingBind，基于 winrio（Registered I/O）+ IOCP 构建环形缓冲接收队列，提供零拷贝高速路径；当 winrio 初始化失败时回退到 StdNetBind。
- default.go / features_*.go / controlfns_*.go / gso_*.go / sticky_*.go / mark_*.go / errors_*.go：按平台（linux、windows、android、default）用 build tag 提供特性探测、控制消息处理、sticky socket、socket mark、错误类型等差异化行为。
- bindtest/：独立测试工具用于验证绑定行为。
依赖方向单向：平台特定文件仅依赖 conn 包内公共接口与 controlfns 提供的 listenConfig 钩子，上层通过 NewDefaultBind() 获取当前平台最优 Bind 实例。
