- 所有握手中间状态（hash、chainKey、临时私钥、共享密钥）在函数返回前显式调用 setZero 清零，防止内存残留泄露。
- 消息编解码采用固定长度的 marshal/unmarshal 方法对 buffer 进行 little-endian 读写，并在入口处校验 len(b) 是否等于预定义的消息大小，否则返回 errMessageLengthMismatch。
- 握手状态通过 `handshakeState` 枚举推进，每个处理函数在进入时检查当前 state 并仅在满足条件时更新为下一状态，保证单向握手流程。
- 对称密钥派生统一通过 KDF2/KDF3 从 chainKey 展开多个输出，派生后立即清零输入 key 与 prk 变量。
- 公钥比较与零值判断使用 subtle.ConstantTimeCompare，避免时序侧信道。
- Curve25519 私钥生成后一律调用 clamp() 设置低位掩码与高位位，确保符合 X25519 规范。
