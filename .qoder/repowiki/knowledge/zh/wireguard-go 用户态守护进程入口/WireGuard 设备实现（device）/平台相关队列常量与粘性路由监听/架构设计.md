本模块由两组按平台划分的 Go 源文件组成，全部属于 `device` 包：
- 队列常量组（queueconstants_*.go）：使用 `//go:build` 标签区分 android、ios、windows 与默认（!android && !ios && !windows）平台，每个文件定义相同的导出符号集合（QueueStagedSize、QueueOutboundSize、QueueInboundSize、QueueHandshakeSize、MaxSegmentSize、PreallocatedBuffersPerPool），编译时仅有一个版本被纳入，从而让上层以统一接口获取各平台最优的队列与内存参数；iOS 版将可变常量声明为 var 以便 Network Extension 在运行时进一步调小。
- 粘性路由监听组（sticky_*.go）：通过 `//go:build linux` 与非 linux 默认实现分别提供 `Device.startRouteListener` 方法；非 Linux 下返回 nil 空实现，Linux 下使用 `golang.org/x/sys/unix` 创建 NETLINK_ROUTE 套接字并启动 goroutine 监听 RTM_NEWROUTE/RTM_DELROUTE 事件，结合 RTM_GETROUTE 查询更新 Peer 端点的源接口标记，实现用户态粘性套接字语义。
依赖方向单向：本模块仅依赖同包的 `Peer`、`Device` 以及外部 `conn`、`rwcancel`、`x/sys/unix`，不反向被这些包引用，是纯平台适配层。
