模块按操作系统通过 Go build tag 拆分实现：`uapi_unix.go` 定义 Linux/Darwin/FreeBSD/OpenBSD 共用的错误码常量、`socketDirectory` 变量及 `UAPIOpen`（创建 `/var/run/wireguard/<iface>.sock` 并返回底层 `os.File`）；`uapi_linux.go` 用 inotify 监控 socket 文件删除事件，`uapi_bsd.go` 用 kqueue + vnode 事件实现相同语义，两者均暴露 `UAPIListen(name, file)` 将传入的 `*os.File` 包装为 `net.Listener` 并通过 `Accept()/Close()/Addr()` 方法族对外；`uapi_windows.go` 则基于子包 `ipc/namedpipe` 监听 `\\.\pipe\ProtectedPrefix\Administrators\WireGuard\<name>`，并在 `init()` 中预加载安全描述符；`uapi_wasm.go` 提供空实现以适配 wasm 目标。`namedpipe/` 子包是独立的 Windows named pipe 实现，封装 `pipe`、`messageBytePipe`、`pipeListener` 等结构，提供 `DialConfig`/`ListenConfig` 配置对象以及 `DialContext`/`Listen` 等标准 `net` 接口，被上层 `uapi_windows.go` 复用。依赖方向单向：平台特定文件 → 共享常量/路径逻辑 → 外部 `golang.org/x/sys/*` 与 `rwcancel`，不反向依赖调用方。
