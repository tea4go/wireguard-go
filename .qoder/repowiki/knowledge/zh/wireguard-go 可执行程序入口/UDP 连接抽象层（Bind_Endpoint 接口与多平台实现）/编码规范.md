- 通过 //go:build 标签将平台差异拆分为 _linux.go、_windows.go、_default.go 等文件，同一接口在不同文件中提供对应实现。
- Bind 实现统一暴露 Open/Send/Close/SetMark/BatchSize/ParseEndpoint 方法，并通过可选的 BindSocketToInterface 与 PeekLookAtSocketFd 接口暴露平台扩展能力。
- 使用 sync.Pool 复用 ipv6.Message 数组与 net.UDPAddr 对象以减少批量收发时的内存分配。
- 通过 controlFns 钩子在 listenConfig 阶段注入平台特定的 socket 选项（如缓冲区大小、sticky socket OOB），使通用监听逻辑与平台细节解耦。
- GSO/GRO 能力通过 supportsUDPOffload 函数探测并在发送/接收路径动态开关，失败时降级为非 offload 模式并记录 ErrUDPGSODisabled。
- 端点类型通过 *Endpoint 断言校验（ErrWrongEndpointType），确保 Send 使用的 Endpoint 与当前 Bind 实现匹配。
